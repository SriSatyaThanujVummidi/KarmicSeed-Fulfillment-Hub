# Fulfillment Hub — Karmic Seed Take-Home Project

A simple Streamlit operational control center for XYZ's e-commerce fulfillment workflow.

## Focus
- Priority/SLA visibility
- Inventory availability and warehouse transfer checks
- Exception management
- Courier and pickup monitoring

## Run locally
```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

The app uses sample data only. The dataset contains approximately 250 daily orders to represent the 200–300 orders/day scenario in the brief.

## Project files
- `app.py` — application
- `data/` — sample operational datasets
- `DATA_DICTIONARY.md` — data definitions
- `PROJECT_EXPLANATION.md` — problem selection and design decisions
- `AI_USAGE_NOTE.md` — AI disclosure template
- `VIDEO_WALKTHROUGH_SCRIPT.md` — walkthrough placeholder

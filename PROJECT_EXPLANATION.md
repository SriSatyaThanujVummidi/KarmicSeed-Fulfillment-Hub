# Project Explanation

## Problems prioritized
1. Priority/SLA visibility - priority orders can miss same-day deadlines.
2. Inventory availability - total stock is not enough when stock is in the secondary warehouse.
3. Exceptions - problems should be captured instead of handled informally.
4. Pickup visibility - packed/staged orders still depend on courier pickup.

## UX principle
The application is organized around the question: **What needs attention right now?** It surfaces priority work, inventory alerts and operational exceptions first, while keeping navigation simple for a warehouse team that is not very comfortable with technology.

## Production improvements
Replace CSVs with a database, add authentication, barcode scanning, live marketplace/courier integrations, persistent issue updates, audit history and notifications.
